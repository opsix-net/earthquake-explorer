APPLICATION CONTRACT
Use Python standard library: csv, pathlib, math. Runtime data access is local.
Search: whitespace-trimmed case-insensitive place substring; blank means all.
Magnitude: finite numeric threshold in [2.5, 10], inclusive match boundary.
Sort: magnitude descending, then UTC time and event ID ascending.
Output: full matching count, maximum, arithmetic mean of reported magnitudes,
and at most ten records. Report skipped source rows. Handle absent or malformed
data files clearly. Catch EOF/interrupt for clean exit. No prediction claims.
The notebook reuses the same application functions. The terminal provides the
repeating menu. The notebook parameter cell supports Run All without waiting
for input, plus an editable search example and full commented source display.

BINDER OPERATION
JupyterLab is the default UI. Open the notebook and Run > Run All Cells.
For menu input: File > New > Terminal; python earthquake_explorer.py.
Binder supplies the Jupyter runtime; .binder/requirements.txt declares no extra
application dependencies. Application behavior is tested locally on Python 3.12;
the host runtime itself is managed by Binder and is not a bit-for-bit image lock.
Record actual remote Python version when a launch succeeds.
Sessions are temporary; inactivity can stop them. Launch links create new
sessions. First builds and busy periods can delay startup. Save changes by
committing source or downloading files; do not rely on session storage.
Never put a temporary server URL or its access token in the final report.
Use the reusable /v2/gh/ launch URL.

JAVA ADAPTATION (PLAN, NOT A VERIFIED JAVA DEPLOYMENT)
Keep the same publication, provenance, manifest, and evidence process. Replace
Python app with Main.java and domain classes, and replace tests with Java tests.
Use a small standard-library CSV format only if parsing remains correct; real
CSV with quoted commas needs a proper parser or deliberate preprocessing.
Provide a pinned JDK via Binder's supported environment configuration, then
validate javac/java in a fresh anonymous session. A notebook may launch Java
through shell cells, while the terminal runs javac Main.java and java Main.
An optional Java notebook kernel is separate from ordinary Java compilation
and adds dependencies; do not reuse the Python kernel configuration unchanged.
Choose Java and dependency versions against current official documentation at
implementation time. Keep a separate runtime, repository, artifacts and tests.
